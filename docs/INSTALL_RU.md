# Установка TeamTrackerGTNH 0.3.1

## Куда ставить

Положите один и тот же файл `teamtrackergtnh-0.3.1.jar`:

- в `mods/` выделенного сервера;
- в `mods/` каждого клиента, которому нужны позиции тиммейтов.

Для GTNH 2.9.0-beta-3 мод рассчитан на штатные:

- ServerUtilities 2.4.9;
- Navigator 1.1.9;
- GTNHLib 0.11.46.

Официальная сборка GTNH beta3 содержит JourneyMap, а не Xaero. Для визуала как
в GT Community Pack Modern на клиент дополнительно нужны:

- `Xaeros_Minimap_21.10.44_Forge_1.7.10.jar`;
- `XaerosWorldMap_1.14.1.33_Forge_1.7.10.jar`.

Xaero на сервер для логики TeamTracker не требуется, но ServerUtilities,
Navigator и сам TeamTracker должны быть доступны согласно их обычной установке
в сборке.

При обновлении полностью остановите сервер и Minecraft, удалите старый
`teamtrackergtnh-*.jar` и положите новый. Мир и
`config/teamtrackergtnh.cfg` удалять не нужно. Не оставляйте две версии JAR
одновременно. Первый переход с 0.2.x на 0.3.x делается сразу на сервере и всех
клиентах, потому что старый FML metadata принимал только точное совпадение версии.

## Как работает доступ

Сервер отправляет координаты только онлайн-игроков из той же команды
ServerUtilities. Сначала участники группируются по team ID, затем перед
добавлением каждой позиции вызывается публичная проверка
`ServerUtilitiesAPI.arePlayersInSameTeam`. Расстояние между игроками не
ограничивает синхронизацию.

Показываются:

- голова игрока на миникарте, включая фиксацию на краю за пределами кадра;
- голова и имя на полноэкранной карте;
- полупрозрачная голова и имя в POV, видимые сквозь блоки.

Игроки из другого измерения не рисуются в текущем измерении.

## Настройки

После первого запуска создаётся `config/teamtrackergtnh.cfg`. Два независимых
хоткея в Controls управляют метками на картах и метками в POV; по умолчанию они
не назначены. Состояние переключателей сохраняется.

Для отсутствия дублей оставьте обычный Xaero Entity Radar / Players включённым:
в пределах миникарты он рисует загруженного игрока, а TeamTracker берёт на себя
удалённую позицию и край миникарты. На полноэкранной карте TeamTracker всегда
рисует собственный слой команды.

Если Entity Radar / Players выключен, установите
`useXaeroRadarForLoadedPlayers=false`, чтобы загруженный teammate не исчезал.
При этом возможен дубль, если Xaero всё же рисует того же игрока.

## Что ещё проверить в игре

0.3.1 собрана как минимальное SRG-совместимое обновление проверенного JAR
0.3.0, поскольку Gradle distribution недоступен в среде сборки. Wire-format,
Java 8 bytecode, runtime-аннотации и состав JAR проверены отдельно. Перед
постоянным использованием проверьте на копии сервера сценарии из
`TEST_MATRIX.md`: два клиента в одной команде, посторонний игрок, выход/вход в
команду, большая дистанция, смена измерения, миникарта, полноэкранная карта и POV.
